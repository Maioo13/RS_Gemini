Admin Console

Gestione riservata eventi, run e gare Run Society

🚀 Modalità Gratuita Serverless: Permette di aggiornare calendari e gare direttamente dal sito pubblico (GitHub Pages) tramite commit sicuro su GitHub, senza dover mantenere alcun server backend.
📖 Come creare il token in 30 secondi ▼

1. Vai su GitHub → Personal Access Tokens (Fine-grained)

2. Clicca "Generate new token" e dagli un nome (es: Admin Run Society).

3. In Repository access seleziona "Only select repositories" e scegli il tuo repo.

4. In Permissions → Repository permissions imposta Contents: Read and write.

5. Clicca Generate token, copialo e incollalo qui sopra.

🖥️ Modalità Server: Per ambienti con backend Node.js attivo (`node server.js`).
